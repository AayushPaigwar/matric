# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and privacy of Matric and its users very seriously.

Because Matric operates with low-level macOS system APIs (`mach_host_self`, `libproc`, `IOKit`, and process signaling), maintaining the security integrity of the monitor is paramount.

If you believe you have discovered a vulnerability:
1. **Do not disclose the issue publicly** on GitHub Issues or social channels.
2. Please open a Private Vulnerability Advisory on GitHub or contact the maintainers directly.
3. Include detailed steps to reproduce, macOS build version, and expected vs actual behavior.

We will acknowledge receipt within 48 hours and work with you on a patch and responsible disclosure timeline.
